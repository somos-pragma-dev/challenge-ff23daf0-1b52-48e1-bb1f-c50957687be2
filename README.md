# Desarrollo de una SPA con React y TypeScript

Necesitas construir una aplicación web de una página (SPA) que gestione un catálogo de productos. Los productos tienen nombre, precio y categoría. El sistema debe permitir la creación, lectura, actualización y eliminación de productos. Debes asegurar que los nombres de los productos sean únicos y que los precios sean valores positivos. La aplicación debe ser escalable y mantener un buen rendimiento a medida que se añadan más productos.
